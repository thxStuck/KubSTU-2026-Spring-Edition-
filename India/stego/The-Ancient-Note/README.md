## समाधान (तरीका 1): Microsoft Word के माध्यम से

### चरण 1: homoglyph-अक्षरों का पता लगाना

1. फ़ाइल **Microsoft Word** में खोलें
2. वर्तनी जाँच चालू करें (अगर बंद है)
3. ध्यान दें — Word कुछ "सामान्य" शब्दों को त्रुटि के रूप में रेखांकित कर सकता है!

**क्यों?** Word पहचानता है कि शब्द में विभिन्न वर्णमालाओं (लैटिन + सिरिलिक) के अक्षर मिश्रित हैं।

4. **खोजें और बदलें** (Ctrl+H) का उपयोग करें:
   - "खोजें" फ़ील्ड में लैटिन अक्षर `o` दर्ज करें
   - "अगला खोजें" दबाएँ
   - कुछ `o` अक्षर नहीं मिलेंगे — ये सिरिलिक `о` हैं!
5. वैकल्पिक: सारा टेक्स्ट चुनें और फ़ॉन्ट को **मोनोस्पेस** (Consolas, Courier New) में बदलें। कभी-कभी सिरिलिक अक्षर थोड़ा अलग प्रदर्शित होते हैं।

### चरण 2: Word में अदृश्य अक्षरों की खोज

1. **Ctrl+Shift+8** दबाएँ (या पैनल पर ¶ बटन) — अमुद्रणीय अक्षर दिखाएँ
2. सामान्य अक्षरों के बीच अजीब मार्कर दिखाई दे सकते हैं
3. टेक्स्ट कॉपी करें, **खोजें** में पेस्ट करें और दृश्य अक्षर हटा दें — अदृश्य अक्षर बचेंगे

## समाधान (तरीका 2): Notepad++ के माध्यम से

### चरण 1: अदृश्य अक्षरों की खोज

1. फ़ाइल **Notepad++** में खोलें
2. मेन्यू: **View → Show Symbol → Show All Characters**
3. सामान्य अक्षरों के बीच बिंदु और मार्कर दिखेंगे — ये zero-width अक्षर हैं!


### चरण 2: सिरिलिक की खोज

1. **Search → Find** (Ctrl+F) खोलें
2. **Mark** टैब पर जाएँ
3. **Regular expression** चालू करें
4. खोज फ़ील्ड में दर्ज करें: `[\x{0400}-\x{04FF}]`
5. **Mark All** दबाएँ
6. सभी सिरिलिक अक्षर हाइलाइट हो जाएंगे!

### चरण 3: अक्षर कोड देखना

1. **HEX-Editor** प्लगइन इंस्टॉल करें या **Plugins → Converter → ASCII to HEX** का उपयोग करें
2. संदिग्ध अक्षर चुनें
3. नीचे स्टेटस बार में उसका कोड देखें

## समाधान (तरीका 5): HEX-एडिटर के माध्यम से

### चरण 1: HxD में खोलना

1. **HxD** डाउनलोड करें (Windows के लिए मुफ़्त hex-एडिटर)
2. `ancient_note.txt` खोलें
3. एन्कोडिंग को UTF-8 पर स्विच करें

### चरण 2: zero-width बाइट्स की खोज

UTF-8 में zero-width अक्षर इस प्रकार एन्कोड होते हैं:

- `E2 80 8B` — Zero Width Space (U+200B)
- `E2 80 8C` — Zero Width Non-Joiner (U+200C)

1. **Ctrl+F** दबाएँ → **Hex-values** टैब
2. `E2 80 8B` और `E2 80 8C` खोजें
3. सामान्य अक्षरों के बीच ऐसी कई अनुक्रम मिलेंगी!

### चरण 3: मैनुअल डिकोडिंग

1. सभी मिले zero-width अक्षरों को क्रम में लिखें:
   - `E2 80 8B` = 0
   - `E2 80 8C` = 1
2. बाइनरी स्ट्रिंग प्राप्त करें
3. 8 बिट के समूहों में विभाजित करें
4. प्रत्येक समूह को ASCII अक्षर में बदलें

**उदाहरण:**

```
01001011 = 75 = 'K'
01110101 = 117 = 'u'
01100010 = 98 = 'b'
...
```

## समाधान (तरीका 6): Python स्क्रिप्ट

स्वचालन के लिए `solve.py` स्क्रिप्ट का उपयोग किया जा सकता है:

```python
#!/usr/bin/env python3

ZW_ZERO = '\u200b'  # Zero Width Space = 0
ZW_ONE = '\u200c'   # Zero Width Non-Joiner = 1

with open('ancient_note.txt', 'r', encoding='utf-8') as f:
    text = f.read()

# zero-width अक्षर निकालें
zw_chars = [c for c in text if c in (ZW_ZERO, ZW_ONE)]

# बाइनरी स्ट्रिंग में बदलें
binary = ''.join('0' if c == ZW_ZERO else '1' for c in zw_chars)

# ASCII में डिकोड करें
flag = ''.join(chr(int(binary[i:i+8], 2)) for i in range(0, len(binary), 8))

print(f"FLAG: {flag}")
```

चलाएँ: `python solve.py`
