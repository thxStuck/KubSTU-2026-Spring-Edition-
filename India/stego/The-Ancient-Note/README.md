Описание задачи
Нам дан текстовый файл ancient_note.txt — якобы старинная рукопись из заброшенной библиотеки. Текст на английском языке, философские размышления о поиске скрытой истины.
Первые наблюдения
При работе с файлом можно заметить странности:
Некоторые слова не находятся через Ctrl+F
При копировании текста в другое место он ведёт себя странно
Размер файла больше ожидаемого для такого объёма текста
В редакторах кода могут появляться предупреждения
Решение (Способ 1): Через Microsoft Word

## Шаг 1: Обнаружение homoglyph-символов

Откройте файл в Microsoft Word
Включите проверку орфографии (если отключена)
Обратите внимание — Word может подчеркнуть некоторые "обычные" слова как ошибки!
Почему? Word распознаёт, что в слове смешаны буквы разных алфавитов (латиница + кириллица).
Используйте Найти и заменить (Ctrl+H):
В поле "Найти" введите латинскую букву o
Нажмите "Найти далее"
Некоторые буквы o не будут найдены — это кириллические о!
Альтернативно: выделите весь текст и смените шрифт на моноширинный (Consolas, Courier New). Иногда кириллические символы отображаются чуть иначе.

## Шаг 2: Поиск невидимых символов в Word

Нажмите Ctrl+Shift+8 (или кнопка ¶ на панели) — показать непечатаемые символы
Между обычными буквами вы можете увидеть странные маркеры
Скопируйте текст, вставьте в Найти и удалите видимые символы — останутся невидимые
Решение (Способ 2): Через Notepad++

## Шаг 1: Поиск невидимых символов

Откройте файл в Notepad++
Меню: View → Show Symbol → Show All Characters
Вы увидите точки и маркеры между обычными символами — это zero-width символы!

## Шаг 2: Поиск кириллицы

Откройте Search → Find (Ctrl+F)
Перейдите на вкладку Mark
Включите Regular expression
В поле поиска введите: [\x{0400}-\x{04FF}]
Нажмите Mark All
Все кириллические символы будут подсвечены!

## Шаг 3: Просмотр кодов символов

Установите плагин HEX-Editor или используйте Plugins → Converter → ASCII to HEX
Выделите подозрительный символ
Посмотрите его код в строке состояния внизу

## Шаг 1: Открытие в HxD

Скачайте HxD (бесплатный hex-редактор для Windows)
Откройте ancient_note.txt
Переключите кодировку на UTF-8

## Шаг 2: Поиск zero-width байтов

В UTF-8 zero-width символы кодируются как:
E2 80 8B — Zero Width Space (U+200B)
E2 80 8C — Zero Width Non-Joiner (U+200C)
Нажмите Ctrl+F → вкладка Hex-values
Ищите E2 80 8B и E2 80 8C
Вы найдёте множество таких последовательностей между обычными символами!

## Шаг 3: Декодирование вручную

Выпишите все найденные zero-width символы по порядку:
E2 80 8B = 0
E2 80 8C = 1
Получите бинарную строку
Разбейте на группы по 8 бит
Конвертируйте каждую группу в ASCII символ
Пример:
01001011 = 75 = 'K'
01110101 = 117 = 'u'
01100010 = 98 = 'b'
...
Решение (Способ 6): Python скрипт
Для автоматизации можно использовать скрипт solve.py:
#!/usr/bin/env python3

ZW_ZERO = '\u200b'  # Zero Width Space = 0
ZW_ONE = '\u200c'   # Zero Width Non-Joiner = 1

with open('ancient_note.txt', 'r', encoding='utf-8') as f:
    text = f.read()

# Извлекаем zero-width символы
zw_chars = [c for c in text if c in (ZW_ZERO, ZW_ONE)]

# Конвертируем в бинарную строку
binary = ''.join('0' if c == ZW_ZERO else '1' for c in zw_chars)

# Декодируем в ASCII
flag = ''.join(chr(int(binary[i:i+8], 2)) for i in range(0, len(binary), 8))

print(f"FLAG: {flag}")
Запуск: python solve.py
