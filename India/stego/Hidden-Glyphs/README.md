- "SECRET DOCUMENT"
- गोपनीय डेटा के बारे में जानकारी
- वर्णमाला: ABCDEFGHIJKLMNOPQRSTUVWXYZ
- संकेत: "The font hides more than you see..." और "Each glyph has a width."

संकेत **फ़ॉन्ट** और **ग्लिफ़ चौड़ाई** की ओर इशारा करते हैं।

### चरण 3: Widths ऐरे निकालना

ऑब्जेक्ट 70 ढूँढते हैं:

```
70 0 obj
[ 670 840 700 1230 1160 1210 1120 510 950 510 950 1020 480 1100 1160 950 1190 490 1000 1160 1040 530 950 520 1140 510 950 1160 1140 490 990 1070 1210 1250 500 500 ... ]
endobj
```

यह फ़ॉन्ट ग्लिफ़ चौड़ाई का ऐरे है। PDF में चौड़ाई आमतौर पर "em space" इकाइयों में दी जाती है (1000 = पूर्ण चौड़ाई)।

### चरण 4: मानों का विश्लेषण

पहले मानों में एक पैटर्न दिखता है:

- 670, 840, 700, 1230, 1160, 1210, 1120, 510...

10 से भाग देने पर:

- 67, 84, 70, 123, 116, 121, 112, 51...

ये ASCII कोड हैं! जाँचते हैं:

- 67 = 'C'
- 84 = 'T'
- 70 = 'F'
- 123 = '{'
- ...

### चरण 5: फ़्लैग डिकोडिंग

#### तरीका A: Python स्क्रिप्ट

```python
widths = [670, 840, 700, 1230, 1160, 1210, 1120, 510, 950, 510, 
          950, 1020, 480, 1100, 1160, 950, 1190, 490, 1000, 1160, 
          1040, 530, 950, 520, 1140, 510, 950, 1160, 1140, 490, 
          990, 1070, 1210, 1250]

flag = ''.join([chr(w // 10) for w in widths])
print(flag)
```

2. From Decimal (स्पेस डिलीमीटर)

4. From Charcode

## तकनीकी व्याख्या

### PDF में Type 3 फ़ॉन्ट क्या है?

Type 3 — एक उपयोगकर्ता-परिभाषित फ़ॉन्ट है, जिसे PostScript ऑपरेटरों का उपयोग करके सीधे PDF में परिभाषित किया जाता है। TrueType या OpenType के विपरीत, Type 3 फ़ॉन्ट पूरी तरह से PDF के अंदर वर्णित होते हैं।

Type 3 फ़ॉन्ट की संरचना:

```
/Type /Font
/Subtype /Type3
/FontBBox [0 0 1500 900]      - границы шрифта
/FontMatrix [0.001 0 0 0.001 0 0] - матрица преобразования
/CharProcs << ... >>          - процедуры рисования глифов
/Encoding << ... >>           - кодировка символов
/FirstChar 48                 - первый символ
/LastChar 122                 - последний символ
/Widths [...]                 - МАССИВ ШИРИН ГЛИФОВ (здесь скрыт флаг!)
```

### यह क्यों काम करता है?

1. **Widths** — एक अनिवार्य ऐरे है जो प्रत्येक ग्लिफ़ के बाद क्षैतिज विस्थापन निर्धारित करता है
2. PDF रीडर इन मानों का उपयोग टेक्स्ट पोजिशनिंग के लिए करते हैं
3. मान कोई भी हो सकते हैं — टेक्स्ट बस अलग-अलग अंतराल के साथ प्रदर्शित होगा
4. PDF को सामान्य रूप से देखने पर कुछ भी संदिग्ध नहीं दिखता

### स्टेगनोग्राफिक विधि

- फ़्लैग के प्रत्येक अक्षर को `ASCII_CODE * 10` के रूप में एन्कोड किया गया है
- 10 का गुणक मानों को वास्तविक फ़ॉन्ट चौड़ाई जैसा बनाता है (आमतौर पर 300-1000)
- फ़्लैग Widths ऐरे की पहली N स्थितियों में वितरित है

## कार्य के वैकल्पिक रूप (विचार)

1. **ToUnicode CMap** — Unicode मैपिंग में फ़्लैग छिपाना, ताकि टेक्स्ट कॉपी करने पर अलग परिणाम मिले

4. **अदृश्य टेक्स्ट** — कस्टम फ़ॉन्ट के साथ सफ़ेद पृष्ठभूमि पर सफ़ेद टेक्स्ट
