## 2. समाधान के चरण

### चरण 1: Java रिवर्सिंग

APK को **Jadx** द्वारा डिकंपाइल करते हैं। `MainActivity` में पाते हैं:

- निर्देशांक जाँच: `45.03547, 38.97531` (क्रास्नोदार का केंद्र)।
- JWT जाँच: एल्गोरिथ्म HS256, सीक्रेट `k3y45`।

### चरण 2: GPS स्पूफ़िंग

एमुलेटर या Fake GPS का उपयोग करके क्रास्नोदार के निर्देशांक सेट करते हैं।

### चरण 3: JWT जनरेशन

सीक्रेट `k3y45` के साथ टोकन बनाते हैं:

- **Header:** `{"alg": "HS256", "typ": "JWT"}`
- **Payload:** `{"user": "ctf_player", "exp": 1999999999}`

### चरण 4: Native रिवर्सिंग

फ़्लैग नेटिव फंक्शन `getFlagNative()` द्वारा दिया जाता है। `libsecurevault.so` निकालते हैं और **Ghidra** में विश्लेषण करते हैं। कुंजी `0x55` के साथ XOR-ऐरे दिखता है।
