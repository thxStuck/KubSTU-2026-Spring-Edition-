यह राइटअप "Capy CTF: The Secret Node" CTF चुनौती का समाधान वर्णित करता है, जो nginx-ui संस्करण 2.3.1 में दो गंभीर भेद्यताओं की श्रृंखला पर आधारित है। लक्ष्य — इन भेद्यताओं का उपयोग करके रिमोट कोड निष्पादन (RCE) या फ़ाइल प्रकटीकरण प्राप्त करना और nginx_ui कंटेनर में /flag.txt फ़ाइल से फ़्लैग प्राप्त करना।
भेद्यताओं का अवलोकन
1. CVE-2026-27944: अप्रमाणित बैकअप और कुंजी प्रकटीकरण
CVE-2026-27944 अप्रमाणित उपयोगकर्ता को /api/backup एंडपॉइंट तक पहुँच देती है। यह एन्क्रिप्टेड आर्काइव लौटाता है जिसमें app.ini सहित पूर्ण बैकअप है। AES-256-CBC डिक्रिप्शन की कुंजी और IV रिस्पॉन्स हेडर X-Backup-Security में ओपन टेक्स्ट में भेजे जाते हैं।
2. CVE-2026-33032 ("MCPwn"): अप्रमाणित MCP मैसेज हैंडलर
/mcp_message एंडपॉइंट में AuthRequired() middleware गायब। Node.Secret का उपयोग करके अप्रमाणित SSE-सेशन स्थापित किया जा सकता है।

## समाधान

चरण 1: `Node.Secret` निकालना (CVE-2026-27944)
/api/backup पर अप्रमाणित GET अनुरोध भेजकर Node.Secret प्राप्त। X-Backup-Security हेडर से AES कुंजी और IV। डिक्रिप्ट → app.ini → [node] Secret।

चरण 2: Nginx कॉन्फ़िगरेशन बदलना और फ़्लैग प्राप्त करना (CVE-2026-33032)
MCP सेशन स्थापित → nginx_config_modify से कॉन्फ़िग बदलना → reload_nginx → /get_flag से फ़्लैग प्राप्त।
