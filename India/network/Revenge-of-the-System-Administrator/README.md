एक सामान्य स्कूल में स्कैंडल हो रहा है। सिस्टम एडमिनिस्ट्रेटर, जिसने लगभग एक साल तक कम वेतन पर काम किया, अचानक नौकरी छोड़ दी, और अपने पीछे एक अजीब नोट छोड़ गया:  *«अगर आपको लगता है कि मेरी नसों पर बचत करना स्कूल को फ़ायदा पहुँचाएगा — अपने अकाउंट चेक करो। मैंने उनके लिए दरवाज़ा खुला छोड़ दिया है जो देखना जानते हैं»*।  प्रिंसिपल घबराया हुआ है: अकाउंटिंग विभाग कहता है कि वित्तीय रिपोर्ट वाले सर्वर तक पहुँच ब्लॉक है, और सभी पासवर्ड बदल दिए गए हैं। आप — आमंत्रित साइबर सुरक्षा विशेषज्ञ हैं। आपका कार्य — स्कूल के नेटवर्क में घुसना, घटनाओं की श्रृंखला को पुनर्स्थापित करना और गबन के प्रमाण ढूँढना।
