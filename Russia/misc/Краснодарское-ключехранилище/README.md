# [misc] Краснодарское ключехранилище

> **Категория:** `misc`  
> **CTF:** KubSTU CTF 2026 Spring

**Категория:** Mobile / Crypto / Geo-Forensics **Сложность:** Medium

## 1. Анализ задачи

Приложение `SecureVault` требует ввода JWT-токена и проверяет местоположение пользователя.

## 2. Шаги решения

### Шаг 1: Реверс Java

Декомпилируем APK через **Jadx**. Находим в `MainActivity`:

- Проверка координат: `45.03547, 38.97531` (Центр Краснодара).
- Проверка JWT: Алгоритм HS256, секрет `k3y45`.

### Шаг 2: Подмена GPS

Используем эмулятор или Fake GPS, чтобы установить координаты Краснодара.

### Шаг 3: Генерация JWT

Создаем токен с секретом `k3y45`:

- **Header:** `{"alg": "HS256", "typ": "JWT"}`
- **Payload:** `{"user": "ctf_player", "exp": 1999999999}`

### Шаг 4: Реверс Native

Флаг выдается нативной функцией `getFlagNative()`. Извлекаем `libsecurevault.so` и анализируем в **Ghidra**. Видим XOR-массив с ключом `0x55`.

**Дешифровка:**

```python

enc = [0x1e, 0x20, 0x37, 0x06, 0x01, 0x00, 0x2e, 0x1f, 0x02, 0x11, 0x0a, 0x1e, 0x3e, 0x27, 0x34, 0x36, 0x3b, 0x3b, 0x3a, 0x31, 0x33, 0x34, 0x0a, 0x12, 0x05, 0x06, 0x3a, 0x18, 0x65, 0x36, 0x3e, 0x34, 0x64, 0x3b, 0x32, 0x3a, 0x0a, 0x18, 0x34, 0x26, 0x21, 0x30, 0x27, 0x2c]
print("".join([chr(b ^ 0x55) for b in enc]))
```
