Техническое объяснение
Что такое Type 3 шрифт в PDF?
Type 3 - это пользовательский шрифт, определяемый непосредственно в PDF с помощью PostScript операторов. В отличие от TrueType или OpenType, Type 3 шрифты полностью описываются внутри PDF.
Структура Type 3 шрифта:
/Type /Font
/Subtype /Type3
/FontBBox [0 0 1500 900]      - границы шрифта
/FontMatrix [0.001 0 0 0.001 0 0] - матрица преобразования
/CharProcs << ... >>          - процедуры рисования глифов
/Encoding << ... >>           - кодировка символов
/FirstChar 48                 - первый символ
/LastChar 122                 - последний символ
/Widths [...]                 - МАССИВ ШИРИН ГЛИФОВ (здесь скрыт флаг!)
Почему это работает?
Widths - обязательный массив, определяющий горизонтальное смещение после каждого глифа
PDF ридеры используют эти значения для позиционирования текста
Значения могут быть произвольными - текст просто будет отображаться с разными интервалами
При обычном просмотре PDF ничего подозрительного не видно
Стеганографический метод
Каждый символ флага кодируется как ASCII_CODE * 10
Множитель 10 делает значения похожими на реальные ширины шрифта (обычно 300-1000)
Флаг распределён по первым N позициям массива Widths
