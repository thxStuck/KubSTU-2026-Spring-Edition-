Видим что почему то сервер не пингуется, хотя кабель воткнут.
Анализ:      Команда show vlan brief на коммутаторе показывает, что сервер висит на      порту Fa0/10 (VLAN 1), а должен быть в VLAN 20 (порт Fa0/2).
Решение:      Переключаем кабель сервера в порт Fa0/2. Теперь сервер находится в      своем логическом сегменте.
Альт.Решение: Переписать работу влан на подключенный порт
