Сложность: easy
Описание
Старый библиотекарь Капибара спрятал секретный свиток в системе, но забыл куда. Говорят, он оставил подсказку в самом сервере… где-то в забытом файле.
Анализ
При проверке ID книги приложение отправляет на сервер XML-запрос:
<?xml version="1.0" encoding="UTF-8"?>
<book>
    <id>1</id>
</book>
Сервер обрабатывает этот XML и возвращает название книги. Если мы можем контролировать XML-структуру, стоит проверить приложение на уязвимость XXE (XML External Entity).

В серверном коде (app.py) используется библиотека lxml с настройками, разрешающими разрешение внешних сущностей:

parser = etree.XMLParser(resolve_entities=True, no_network=False)
root = etree.fromstring(xml_data, parser=parser)
Эксплуатация
Уязвимость XXE позволяет определять внешние сущности, которые парсер попытается разрешить. Мы можем использовать это для чтения локальных файлов на сервере.
