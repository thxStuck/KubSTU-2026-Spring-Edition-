Открываем encrypt.py и видим, что флаг шифруется в три слоя, один за другим

1.  XOR с потоком байтов из кастомного генератора cursed_prng(13, ...)
2.  функция forgotten_cipher с ключом, полученным из sha256(b"Unlucky13")
3.  RSA с e = 3

В output.txt нам дали только n, e и c результат RSA шифрования. Чтобы добраться до флага, нужно пройти все три слоя в обратном порядке: сначала RSA, потом  слой 2, потом слой 1


Сначала RSA

Замечаем, что e = 3. Это очень маленькая публичная экспонента.

RSA работает так: c = m^e mod n, то есть c = m³ mod n.

Но наш флаг это \~52 байта (416 бит), а n — это 2048 бит. Значит m³  это примерно 1248 бит, что всё ещё меньше n (2048 бит). Получается, при возведении в куб mod не работает, и c = m³ — просто обычное число, без всякого mod

Достаточно просто извлечь кубический корень из c


Теперь RC4

Теперь смотрим на функцию forgotten_cipher в encrypt.py. Она нигде не названа по имени, но если присмотреться к коду инициализация массива S от 0 до 255, перемешивание по ключу, затем генерация потока через PRGA это RC4

RC4 это поточный шифр, и он симметричный, а значит шифрование и расшифровка это одна и та же операция. Прогоняем те же данные через ту же функцию с тем же ключом


XOR


Последний слой самый простой. Флаг был поксорен с потоком из кастомного PRNG с сидом=13. XOR симметричен, поэтому просто генерируем тот же поток и ксорим
